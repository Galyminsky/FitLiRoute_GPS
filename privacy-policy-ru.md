# Политика конфиденциальности FITLiROUTE GPS

**Дата последнего обновления: 10 ноября 2026 года**

## 1. Общие положения

Настоящая Политика конфиденциальности описывает, как мобильное приложение **FITLiROUTE GPS** («Приложение») получает, использует, хранит и защищает данные пользователей.

FITLiROUTE GPS предназначено для записи GPS-маршрутов, отображения перемещения на карте, расчёта расстояния, времени и скорости, а также просмотра сохранённых маршрутов.

По вопросам конфиденциальности можно обратиться по электронной почте: **galyaminsky@gmail.com**.

## 2. Доступ к местоположению

Для выполнения основных функций Приложение запрашивает доступ к точному местоположению устройства.

Данные геолокации используются для:

- определения текущего местоположения;
- построения и записи пройденного маршрута;
- расчёта пройденного расстояния и скорости;
- отображения маршрута на карте;
- сохранения истории маршрутов на устройстве.

Запись маршрута запускается пользователем посредством кнопки **START**.

Во время активной записи Приложение может продолжать определять местоположение, даже когда оно свёрнуто или экран устройства заблокирован. Для этого используется служба переднего плана Android (Foreground Service) с системным уведомлением.

Запись прекращается после завершения пользователем или при других предусмотренных Приложением условиях остановки.

Пользователь может отозвать разрешение на геолокацию в настройках Android. Без соответствующего разрешения функции GPS-записи будут недоступны.

## 3. Хранение маршрутов

Записанные GPS-маршруты, включая координаты, название маршрута и связанную статистику, сохраняются локально во внутреннем хранилище устройства.

Для хранения завершённых маршрутов используется база данных Room. Для временного сохранения незавершённой записи используются локальные файлы приложения.

FITLiROUTE GPS не предоставляет собственного сервиса учётных записей или облачной синхронизации маршрутов.

Приложение не содержит реализованной разработчиком функции отправки сохранённой истории маршрутов на собственный сервер.

Данные маршрутов не включаются в стандартное резервное копирование приложения, согласно его текущей конфигурации.

## 4. Аналитические данные

Приложение использует **Google Firebase Analytics** для получения статистической информации о работе и использовании Приложения.

Firebase Analytics может автоматически обрабатывать данные, включая:

- события запуска и использования Приложения;
- идентификаторы экземпляра приложения;
- сведения об устройстве, операционной системе и версии Приложения;
- диагностические и технические параметры, предусмотренные используемым SDK.

Такие данные могут передаваться компании Google и обрабатываться в соответствии с её условиями и политикой конфиденциальности.

FITLiROUTE GPS не содержит специально реализованной передачи записанной истории маршрутов или координат маршрутов в Firebase Analytics. При этом обработка данных самим SDK определяется его используемой версией и настройками.

Дополнительная информация: https://policies.google.com/privacy

## 5. Картографические данные

Для отображения карты Приложение использует библиотеку **osmdroid** и картографические данные OpenStreetMap.

При загрузке картографических фрагментов (тайлов) сетевые запросы направляются к соответствующему картографическому сервису.

В результате поставщик картографических тайлов может получать технические данные сетевого запроса, включая IP-адрес устройства и сведения о запрашиваемой области карты.

Запросы картографических тайлов не являются функцией публикации или облачного хранения записанной истории маршрутов.

Дополнительная информация: https://osmfoundation.org/wiki/Privacy_Policy

## 6. Передача данных третьим лицам

Для работы отдельных функций Приложения используются сторонние сервисы:

- **Google Firebase Analytics** — аналитика использования Приложения;
- **поставщик картографических тайлов OpenStreetMap** — загрузка фрагментов карты.

Обработка данных этими сервисами осуществляется в соответствии с их собственными правилами и применимыми соглашениями.

Приложение не предоставляет пользователям функции публичного размещения маршрутов или обмена ими через собственный сервер разработчика.

## 7. Безопасность данных

Локальные маршруты хранятся во внутреннем хранилище Приложения с использованием механизмов изоляции приложений Android.

Для работы приложения применяются стандартные механизмы безопасности платформы Android и HTTPS-соединения для поддерживаемых внешних сервисов.

При этом абсолютная безопасность любого способа хранения или передачи данных не может быть гарантирована.

## 8. Сроки хранения и удаление данных

Сохранённые маршруты остаются на устройстве, пока пользователь не удалит их в Приложении или не удалит данные самого Приложения.

Пользователь может удалять сохранённые маршруты через интерфейс FITLiROUTE GPS.

Удаление данных Приложения через настройки Android или удаление Приложения обычно приводит к удалению его локальной базы данных и файлов.

Аналитические и технические данные, обрабатываемые Google Firebase Analytics и картографическими сервисами, могут храниться этими поставщиками в соответствии с их собственными сроками хранения.

По вопросам обработки данных можно написать на **galyaminsky@gmail.com**.

## 9. Управление разрешениями

Пользователь самостоятельно управляет доступом Приложения к геолокации через настройки Android.

Отказ в предоставлении разрешения или его отзыв ограничивает функции, которым требуется местоположение, но не предполагает автоматического удаления ранее сохранённых маршрутов.

## 10. Изменения политики

Настоящая Политика может обновляться при изменении функций FITLiROUTE GPS, используемых технологий или применимых требований.

Актуальная версия размещается на публичной странице Политики конфиденциальности. Дата последнего обновления указывается в начале документа.
